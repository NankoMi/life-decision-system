# 🧭 life-decision-system — 人生决策操作系统

> **Know the laws. Then become yourself.**
> 把"数据化人生分析"从刷到的视频，变成一台随时可调用的决策机器。

一个面向 AI Agent 的**四层人生决策技能**：从世界观稳态 → 证据分级 → 最优停止 → 神经网络打分，回答人类最高频的四类问题——

```
"这是不是命？"   →  第0层 · 60+条定律世界观
"这事值不值？"   →  第1层 · 654条证据分级条目（只引期刊论文与官方文件）
"什么时候出手？" →  第2层 · 最优停止 / 37%法则
"选哪个更好？"   →  第3层 · Laya 决策模型（421M 非自回归打分器，32.8ms/次）
```

**它不是鸡汤合集，是一台流水线。** 每个结论都要求注明：出处（第几节第几条）/ 法则参数（37% 观望期 / λ≈2.25）/ 模型置信度。查不到就说查不到——**禁止编数字**。

## 🧮 Laya 计算方法（第 3 层引擎原理）

### 非自回归决策模型（System-1）

底座为 **ModernBERT-large（395M 双向编码器）+ 决策头**，合计 **421M 参数**。与生成式 LLM 逐 token 解码不同，Laya **单次前向传播直接输出决策分布**——结构上不存在幻觉，输出格式永远合法，单次推理延迟低至 **32.8ms**（官方基准，Jev 同类任务 236–276ms）。

### 三个原语（输出空间仅此三种）

| 原语 | 数学形式 | 输出 |
|---|---|---|
| `choice` | $P(y=c \mid s) = \mathrm{softmax}(W_c h_{[CLS]})_c$ | 选项 + 全概率分布 + 置信度 |
| `score` | $\hat{y} = \sum_k k \cdot P(y=k \mid s)$（序数量表期望） | 1–5 期望分 + 等级分布 |
| `noul` | $P(\mathrm{true} \mid s)$ 经温度校准 | 0–1 校准概率 |

其中 $h_{[CLS]}$ 为编码器全局表征，决策头为浅层 MLP（`head_layers: 2`）。

### 微调流水线（本仓库已内置）

1. **数据合成**：`finetune/build_book_dataset.py` 将书库 667 条条目自动转为 787 条标注样本（score 软标签按收益量级 + 成本修正 + 证据等级锐度；反面清单 → noul 负样本）
2. **训练**：官方 `laya-train`（soft-CE 损失，选项随机置换防位置过拟合），3 epochs，4070 TiS 实测 **48 秒**
3. **校准**：温度校准 `fit_temperatures`——不做 ECE 0.466，做了 **ECE 0.081**（好 5 倍）
4. **闭环**：每次真实决策记录 `decisions.jsonl`（问题/选项/最终选择/结果），攒够即 v2 微调——**模型随使用越来越懂你**

> 底座零样本即随机（~0.35），微调后 typed-decisions 基准 0.766、校准误差 ECE 0.081——**小模型 + 领域微调，专治"反射性判断"这类大模型最贵又最容易出错的活。**

## 📦 安装

```bash
# 1. 放进技能目录
unzip life-decision-system-skill.zip -d ~/.workbuddy/skills/

# 2.（可选）启用第3层打分
python -m venv .venv && .venv/bin/pip install laya torch transformers   # ≈2.5GB

# 3.（可选）微调你自己的打分模型
cd finetune
python build_book_dataset.py
python -m laya.train_cli --data book_dataset.jsonl --base ../laya-model --out ./ckpt-mine --epochs 3 --device cuda

# 4. 写入你的个人纪律（LOCAL.md 不入库不分发）
echo "## 我的投资纪律" >> LOCAL.md
```

模型路径自动解析：`--base` → 环境变量 `LAYA_MODEL` → `finetune/ckpt-*` → `laya-model/` → HF 在线。
