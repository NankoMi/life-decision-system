## 一、视频的核心结构（星空隐喻）

1. 提问：人生是随机的，还是早就写好的？
2. 展开一张星空图：**38 条定律 = 四个星座**（感情 / 金钱 / 事业 / 人生）
3. 转折：**"每一颗星，都是一万个人的平均"**（x̄=(1/n)Σxᵢ）——每条定律都是一万个人样本的统计结果
4. 但是：**"你的人生，只有一次"**——统计规律属于总体，你只活自己这一个样本
5. 双联句（视频给的答案）：**"遇见谁，也许是随机的；会怎样，也许早有规律"**
6. 落点：**"认清规律，然后，成为自己"（Know the laws. Then become yourself.）**

**本决策系统的立场由此而来**：定律当地图用，不当判决书用。规律是先验（"写好的"部分），单样本怎么走仍由选择决定（"随机的"部分）——这正是三层流水线存在的意义。

## 四、使用规则（加入决策速判）

- 用户问"是不是命 / 有没有意义 / 是不是水逆 / 挣扎有没有用" → **先进本层**：引用对应定律（№12 泊松、№07 习得性无助、"一万人的平均"）稳住世界观，再进第 1 层查证据
- 引用定律时注明编号（如"№04 损失厌恶，痛感放大 2.25 倍"）
- 禁止用定律给人贴标签下判决——视频落点"成为自己"：规律解释过去，不锁死未来
